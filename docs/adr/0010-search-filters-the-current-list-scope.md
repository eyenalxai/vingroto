# Search filters the current list scope

Search does not have a scope of its own: `/` filters whatever list is currently shown — a mailbox, one of the unread views, or All emails — and the mailbox tree selection keeps defining that scope. Local matching is fuzzy (subsequence plus bounded typos) over cached headers, recipients, snippets and cached bodies; a remote IMAP search runs after the query settles in the mailboxes that scope covers, uses an exact TEXT criterion per term (IMAP cannot rank or fuzz), and pages through hits 100 at a time. Remote hits are imported into the cache as ordinary messages and remembered as matches for their query, so a message found only by its body stays visible and behaves like synced mail. A muted mailbox is only searched remotely when it is the selected list.
